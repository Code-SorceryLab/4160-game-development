# Part B — bug reports

One block per bug. Copy the template. A bug no one can reproduce from your
steps will not be counted.

- **Severity:** A = crash or the game cannot be finished; B = serious but
  playable; C = minor.
- **Priority:** fix now / soon / later — and one line on why.
- **Rule:** the rule in `SPEC.md` the game breaks.

---

```text
ID       B-01
TITLE    (short and specific: what goes wrong, where)
RULE     R..
BUILD    bug-hunt starter, <your OS>
SETTINGS Difficulty .., Language .., Shake .., Assist ..
STEPS    1.
         2.
         3.
EXPECT
ACTUAL
REPRO    ../5
SEV      A / B / C
PRIORITY fix now / soon / later: why
FOUND BY test case T-.. / pairwise row .. / flow path P-.. / exploring
```

Evidence (optional): screenshot or short clip in the folder, named `B-01.png`.
