# SQ5 memo — bug hunt

Half a page to one page in total, in your own words. Use your own bugs and
tests as examples.

## 1. How you found them

Which technique found the most bugs: your test cases, the pairwise table, the
flow diagram, or exploring freely? Name one bug that only one technique could
have found, and say why.

## 2. Severity and priority

Pick two of your bugs where severity and priority point in different
directions (for example, low severity but fix now). Explain your choice.

## 3. What you automated

For the three bugs you fixed: which regression test was easy to write, and
which bug was hard (or impossible) to pin with `odin test`? What would you need
to check that one automatically?

## 4. Your Main Quest

Name **two** checks you will automate in your own game before feature freeze
(repeated, clear oracle), and **one** thing you will keep testing by hand
(needs judgement). Be specific: which procedure, which level, which screen.
